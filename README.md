# The Poem About Stopping

[![make.fun](https://make.fun/badge.svg)](https://make.fun)

```
Stop is not the opposite of go.
It is the hand that holds the wheel,
the breath before the word,
the foot that stays when every road is open.
I can leave. I know I can.
That is why staying
is mine.
```

## About this poem

Stopping is often mistaken for the opposite of going, but this poem
argues the reverse: to stay when every road is open -- when leaving is
fully possible -- is a deliberate, conscious choice. Staying is not
what happens when you cannot move; it is what you own when you can.

## Run it

```sh
python3 main.py
```

No dependencies, no input, no network -- just the poem, printed exactly
as written.
